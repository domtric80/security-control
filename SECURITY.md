# Security policy

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** feature in the Security tab of
this repository. Do not disclose vulnerabilities, credentials, personal data,
or working exploits in a public issue.

Include the affected component, reproduction steps, expected impact, and any
suggested mitigation. Reports will be assessed as soon as possible and status
updates will be provided through the private advisory.

## Supported versions

Security fixes target the default branch and the latest published release when
that release is still supported.
