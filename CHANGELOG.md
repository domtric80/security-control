# Changelog

## v0.1.0 - 2026-08-17

Prima release pubblica di Security Control.

### Incluso

- Questionari dinamici con salvataggio risposte e import XLSX.
- Catalogo requisiti, requisiti standard e requisiti specifici di progetto.
- Motore regole per requisiti e servizi con gruppi logici configurabili.
- PIR con riunioni, partecipanti, allegati, stato requisiti e report PDF.
- Eccezioni di sicurezza con data di rientro, approvatore e calendario.
- RBAC con permessi CRUD per funzione.
- Autenticazione locale, LDAP e OIDC/Keycloak-compatible.
- Integrazione AI con Ollama e provider OpenAI-compatible.
- Export CSV, XLS, PDF e formato Confluence.
- Hardening base per sessioni, CSRF, upload, export e Docker locale.
